# Qatar4u Mobile

Qatar4u • معاينة 1.1.0

واجهة هاتف خفيفة بأيقونات دائرية وعربية وإنجليزية، مع إدارة التطبيقات المرئية والعناية بالجهاز. النسخة مستقلة عن Qatar4u TV.

مسار البناء mobile-build يفحص الاختبارات وlint ثم يبني APK تجريبيًا بتوقيع debug وملف SHA256. لا ينشر إصدارًا عامًا ولا يعدّل main ولا يثبّت على الهاتف. توقيع الإنتاج يُجهّز قبل الإصدار المستقر.

التنظيف يقتصر على مؤقتات هذا التطبيق. إلغاء تثبيت تطبيقات المستخدم يحتاج تأكيدًا ثم شاشة تأكيد Android. تطبيقات النظام تُدار عبر إعدادات Android دون حذف آلي. الوضع المتقدم غير مضاف.

معاينة التصميم: docs/mobile/preview.html. حالة التحقق والقيود: docs/mobile/STATUS.md.

## الواجهة والإعدادات

- أربعة أعمدة وأيقونات دائرية، مع بحث ومفضلة محفوظة.
- خلفيات ثابتة بالذهبي والعنابي والأزرق والأسود، وخمس خلفيات قطرية، وصورة يختارها المستخدم.
- لغة عربية باتجاه RTL وإنجليزية، وخط Cairo محلي.
- اختيار المدينة، صلاة أم القرى محليًا وتمييز الصلاة القادمة، وطقس اختياري أثناء ظهور الواجهة فقط.
- عرض RAM والتخزين، تنظيف مؤقتات التطبيق، وإدارة تطبيقات المستخدم والنظام عبر تأكيدات Android.

[تعليمات التثبيت والتراجع بالعربية](docs/mobile/INSTALL_AR.md) • [English trial guide](docs/mobile/INSTALL_EN.md)

المشروع مبني على Qatar4u TV ومعدّل للهاتف. لم يُختبر حتى الآن على هاتف 17 Pro Max الخاص بالمالك، ولا تنتقل نتيجة اختبار HUAWEI Mate X6 من المشروع السابق إلى هذه النسخة.

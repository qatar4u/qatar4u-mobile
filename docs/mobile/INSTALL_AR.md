# تجربة Qatar4u Mobile

1. افتح مستودع qatar4u/qatar4u-mobile ثم Actions، واختر أحدث بناء ناجح من main.
2. نزّل Qatar4u-Mobile-preview من Artifacts وفك ضغطه. هذه نسخة تجريبية موقّعة بتوقيع debug، وليست إصدار متجر.
3. افتح الهاتف، وصله بكابل USB، وشغّل PowerShell من مجلد platform-tools.
4. افحص الاتصال:

```powershell
.\adb.exe devices -l
```

5. تحقق من SHA256 للملف وقارنه بالسطر الموجود في SHA256SUMS داخل الحزمة:

```powershell
Get-FileHash "$env:USERPROFILE\Downloads\Qatar4u-Mobile-preview\Qatar4u-Mobile-1.0.0-preview.apk" -Algorithm SHA256
```

6. بعد موافقتك على التثبيت، عدّل مسار الملف إذا اختلف ثم نفّذ:

```powershell
.\adb.exe install -r "$env:USERPROFILE\Downloads\Qatar4u-Mobile-preview\Qatar4u-Mobile-1.0.0-preview.apk"
.\adb.exe shell am start -n net.qatar4u.mobile/net.qatar4u.mobile.MainActivity
```

لا تحذف بيانات التطبيق إذا ظهرت مشكلة توقيع. التوقيع التجريبي قد يختلف بين مهام البناء؛ يجب تثبيت توقيع ثابت قبل اعتماد تحديثات مستقرة.

## ما تختبره قبل اعتماد الواجهة

- العربية ثم الإنجليزية، اتجاه القوائم، الأزرار، لوحة المفاتيح والتنقل والرجوع.
- الخلفيات الأربع وخلفيات قطر الخمس والصورة المخصصة، ثم إغلاق التطبيق وإعادة فتحه للتحقق من الحفظ.
- فتح التطبيقات، البحث، المفضلة، تصفية المستخدم والنظام، والعودة بعد فتح معلومات أحد التطبيقات.
- اختيار المدينة ومواقيت الصلاة المحسوبة محليًا بطريقة أم القرى؛ قارنها بتقويم المدينة الرسمي قبل الاعتماد.
- الطقس معطل افتراضيًا. فعّله فقط إذا أردت إرسال إحداثيات مركز المدينة إلى Open-Meteo؛ التحديث أثناء ظهور واجهة الهاتف فقط.
- تنظيف مؤقتات التطبيق بعد التأكيد. لا تجرب إزالة تطبيق مهم؛ إلغاء التثبيت قد يحذف بياناته المحلية.
- لا توجد أدوات روت أو Shizuku أو حذف صامت أو ادعاء تسريع RAM.

## الرجوع

افتح إعدادات Android > التطبيقات الافتراضية > تطبيق الشاشة الرئيسية، واختر الواجهة السابقة. يمكنك فتح هذا التطبيق كتطبيق عادي قبل جعله الواجهة الافتراضية. لا تحذف الواجهة الأصلية.

بعد انتهاء التجربة عطّل تصحيح أخطاء USB من خيارات المطوّر، ويمكنك إلغاء تراخيص تصحيح USB من الشاشة نفسها.

## حدود التحقق

اختبارات الكود وlint لا تثبت جودة العرض على الهاتف. المعاينة HTML توضيحية؛ اختبار الهاتف الفعلي والتوافق مع إعدادات الشركة ما زالا مطلوبين. بيانات العتاد والنظام المعروضة مصدرها النظام ولا تعادل فحصًا مستقلًا للمكونات.
